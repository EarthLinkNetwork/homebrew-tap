# EarthLink Network Homebrew tap

The Homebrew casks of EarthLink Network apps.

```sh
brew install --cask earthlinknetwork/tap/jotlio
```

Each app's downloads and update feed live in that app's own release repository (for Jotlio:
EarthLinkNetwork/jotlio-releases). The apps update themselves (Sparkle); `brew upgrade --greedy` is
not needed. The casks here are committed only by each app's release workflow.
