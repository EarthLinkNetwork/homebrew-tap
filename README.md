# EarthLink Network Homebrew tap

```sh
brew install --cask earthlinknetwork/tap/jotlio
```

This repository holds the Homebrew casks and the release downloads (DMG and the Sparkle update feed
`appcast.xml`) of Jotlio for Mac. The app updates itself (Sparkle); `brew upgrade --greedy` is not
needed. The releases here are published only by Jotlio's release workflow.
